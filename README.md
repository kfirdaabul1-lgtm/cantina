# ניהול סניף לגו קנטינה נוריות: מדריך התקנה

אפליקציה אחת לניהול הסניף, עם עמוד מנכ״ל שמסכם את כל ההוצאות של החודש (ספקים ועובדים), ועוד שני חלקים:

- **משמרות:** עובדים נכנסים מהנייד, מצטרפים עם קוד ומסמנים זמינות. המנהל משבץ, מפרסם ורואה עלויות. המחלקות הן עובד פס, קופה, שף סושי ושף נודלס. סוגי שכר: שעתי, גלובלי ומזומן.
- **ספקים:** רשימת ספקים, העלאת החשבונית החודשית של כל ספק (צילום או PDF), סיכום כמה יצא בכל חודש ומה עוד לא שולם, שליחת כל החשבוניות של החודש לרואה החשבון במייל אחד, ומעקב מחירים לכל פריט אצל כל ספק עם התראה כשמשהו מתייקר.

את חלק הספקים רואים רק מנהלים. עובדים רואים רק את המשמרות שלהם.

ההתקנה לוקחת בערך 20 דקות, פעם אחת. **זו מערכת נפרדת לגמרי מזו של המלונות**: פרויקט Firebase חדש ומאגר GitHub חדש.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `config.js` | פרטי החיבור ל-Firebase, ממלאים בשלב 3 |
| `firestore.rules` | כללי האבטחה, מדביקים ב-Firebase בשלב 2 |
| `README.md` | המדריך הזה |

## שלב 1: פרויקט Firebase חדש

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) עם kfirdaabul1@gmail.com.
2. **Create a project**, שם: `cantina`. מבטלים Google Analytics ולוחצים **Create**.
3. **Build ← Authentication ← Get started**.
4. בלשונית **Sign-in method** בוחרים **Google**, **Enable**, בוחרים מייל תמיכה ו-**Save**.

## שלב 2: מסד הנתונים וכללי האבטחה

1. **Build ← Firestore Database ← Create database**.
2. מיקום: **eur3 (europe-west)**. מצב: **Start in production mode**. **Create**.
3. בלשונית **Rules** מוחקים הכל ומדביקים את כל התוכן של `firestore.rules`.
4. **Publish**.

> אם כבר התקנת את הגרסה הקודמת (רק משמרות): צריך להדביק שוב את `firestore.rules` החדש וללחוץ **Publish**, אחרת חלק הספקים יגיד "אין לך הרשאה".

## שלב 3: מחברים את האפליקציה

1. גלגל השיניים ליד **Project Overview ← Project settings**.
2. ב-**Your apps** לוחצים על `</>` (Web), נותנים שם ו-**Register app**.
3. מעתיקים את הערכים מ-`firebaseConfig` לקובץ `config.js`.
4. שומרים.

> הערכים האלה לא סודיים. מה שמגן על הנתונים זה כללי האבטחה משלב 2.

## שלב 4: מעלים לאוויר (GitHub Pages, בחינם)

1. ב-[github.com](https://github.com): **New repository**, שם: `cantina`, **Public**, **Create repository**.
2. **uploading an existing file**, גוררים את ארבעת הקבצים, **Commit changes**.
3. **Settings ← Pages**: Source **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, **Save**.
4. אחרי דקה-שתיים מופיעה הכתובת, למשל `https://USERNAME.github.io/cantina/`.

## שלב 5: מאשרים את הכתובת ב-Firebase

1. **Authentication ← Settings ← Authorized domains ← Add domain**.
2. מוסיפים `USERNAME.github.io` (בלי `https://` ובלי `/cantina`).

## שלב 6: כניסה ראשונה

1. פותחים את הכתובת ונכנסים עם Google (kfirdaabul1@gmail.com). אתה בעל המערכת.
2. למעלה יש ארבעה אזורים: **מנכ״ל**, **משמרות**, **ספקים**, **הגדרות**.
3. ב**הגדרות**:
   - בודקים את שעות המשמרות בכל מחלקה ולוחצים **שמירת ההגדרות**.
   - בכרטיס "קוד הצטרפות לעובדים" לוחצים **יצירת קוד**.
   - בכרטיס "ספקים ורואה חשבון" ממלאים את השם והמייל של רואה החשבון ואת אחוז ההתראה על התייקרות (ברירת מחדל 5%).
   - בכרטיס "המסעדה", תחת "נתונים התחלתיים", לוחצים **ייבוא**. זה מכניס את 8 הספקים ואת 6 החשבוניות שהוכנו מראש, כולל הפריטים והמחירים. את קבצי החשבוניות עצמם מעלים אחר כך לכל חשבונית.

## שלב 7: עובדים ומנהלים

- **עובדים:** במשמרות ← סידור ← **שליחה לעובדים**. ההודעה כוללת קישור וקוד הצטרפות.
- **מנהל משמרת:** נרשם כמו עובד. אחר כך במשמרות ← עובדים פותחים את הכרטיס שלו ומסמנים **מנהל במערכת**. שים לב: מנהל רואה גם את הספקים והחשבוניות.

## איך עובדים עם הספקים

**ספקים ← ספקים ← הוספת ספק.** שם, קטגוריה, איש קשר, טלפון ותנאי תשלום. פעם אחת לכל ספק.

**ספקים ← חשבוניות ← העלאת חשבונית.**
1. בוחרים ספק וחודש, ממלאים מספר חשבונית וסכום כולל מע״מ.
2. **צילום חשבונית** פותח את המצלמה בטלפון. **העלאת PDF או תמונה** בוחר קובץ. אפשר כמה קבצים לחשבונית.
3. **פריטים ומחירים** (לא חובה, אבל בלי זה אין מעקב מחירים): שם הפריט, יחידה, כמות ומחיר ליחידה לפני מע״מ. מהחשבונית השנייה של אותו ספק, הכפתור **הפריטים הקבועים של הספק** ממלא את כל הפריטים, ונשאר רק להקליד מחירים. ליד כל מחיר מופיע מה היה בפעם הקודמת, ובאדום אם עלה.
4. מסמנים **שולם** כשמשלמים.

במסך החשבוניות רואים לכל חודש: כמה יצא, כמה עוד לא שולם, אילו ספקים עוד לא שלחו חשבונית, והשוואה לחצי השנה האחרונה.

**מעקב מחירים.** כל הפריטים מכל הספקים, עם המחיר האחרון, הקודם, אחוז השינוי ומאז הפעם הראשונה. פריט שהתייקר מעל הסף מסומן באדום, ולחיצה עליו מראה גרף והיסטוריה.

**שליחה לרואה החשבון.** בחשבוניות לוחצים **שליחה לרואה החשבון**, מסמנים אילו חשבוניות ולוחצים **הכנת קבצים**. מצורפת גם טבלת סיכום שנפתחת באקסל.
- **מהטלפון:** **שליחה מהטלפון עם הקבצים** פותח את חלון השיתוף. בוחרים Gmail, וכל הקבצים כבר מצורפים למייל אחד עם נושא וטקסט. המייל של רואה החשבון מועתק אוטומטית, רק מדביקים אותו בשדה "אל".
- **מהמחשב:** **הורדת ZIP**, ואחר כך **פתיחת Gmail** שנפתח עם הנמען, הנושא והטקסט. גוררים את ה-ZIP למייל.

אחרי השליחה החודש מסומן "נשלח לרואה החשבון".

> אפליקציה שיושבת על GitHub Pages לא יכולה לשלוח מייל בעצמה, ולכן השליחה עוברת דרך Gmail שלך. שליחה אוטומטית לגמרי דורשת שירות מייל בתשלום, ואפשר להוסיף אותה בהמשך.

## עלויות ונפח

- **Firebase (Spark):** חינם. הקבצים של החשבוניות נשמרים בתוך מסד הנתונים, ותמונות מוקטנות אוטומטית לכ-300KB. במסלול החינמי יש 1GB, שמספיק לאלפי חשבוניות. PDF אפשר עד 8MB.
- **GitHub Pages:** חינם.
- **כניסה עם SMS (לא חובה):** דורשת חשבון Blaze ומשלמים לכל הודעה. מפעילים **Phone** ב-Sign-in method ומשנים ב-`config.js` את `enablePhone` ל-`true`.
